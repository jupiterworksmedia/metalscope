# Metal Scope India — Homepage Concept

Responsive Next.js 15 website with interactive navigation, solution cards, sector sections, project filters, rail division, and RFQ enquiry UI.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
